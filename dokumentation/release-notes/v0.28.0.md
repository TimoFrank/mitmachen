# Vier Modulzeichen und die neue Kartenübersicht

#Mitmachen verbindet Menschen, die die digitale Versorgung gemeinsam gestalten. Der Versorgungs-Kompass macht Kontakte, Organisationen, Wissen und Aktivitäten sichtbar und hilft dem Netzwerk, die Versorgung gemeinsam weiterzuentwickeln.

## Das steckt in Version 0.28.0

Auf der Startseite umgeben vier animierte Modulzeichen die Begrüßung. Oben links steht der Versorgungs-Kompass. Der Kreis „Versorgung“ öffnet direkt die Kartenübersicht.

## Neue und verbesserte Funktionen

### Vier Zeichen für vier Module

Der Rundkompass steht für Versorgung. Zwei Menschen nebeneinander kennzeichnen Stakeholder. Für Hospitation zeigt das Zeichen Deutschland mit einer kurzen Kompassnadel. Zwei Programmpunkte auf einer Karte stehen für Formate.

### Die Kontaktliste neben der Karte

Auch bei mittlerer Fensterbreite lässt sich die Liste links neben der Deutschlandkarte bis zum letzten Kontakt durchscrollen. Auf den Unterseiten folgen Suche und Werkzeuge direkt auf die Navigation. Vorlesesoftware kann den jeweiligen Seitentitel weiterhin ansagen.

### Was sich gegenüber der bisherigen Demo ändert

GitHub Pages übernimmt auch die Änderungen der Demo vom 12. November. Dazu gehören die verstellbare Seitenleiste, persönliche Favoriten für Kontakte und Organisationen sowie die neue Anordnung von Profil und Teams. Wer die selbst betriebene Demo unter `versorgungs-kompass.de/demo` nutzt, kennt diese Bedienung bereits. Die neuen Modulzeichen und die korrigierte Kontaktliste werden zuerst auf GitHub Pages veröffentlicht.

Die Kurzanleitung im Repository beschreibt Versorgung und Hospitation in der gematik-Fassung. Sie steht in zwei Fassungen bereit. ## Technische Änderungen

Der TYPO3-Konnektor ist ein separat installierbares Serverpaket. GitHub Pages und die selbst betriebene Demo liefern ihn nicht aus. Für das Paket aktualisiert diese Version TYPO3 Core und Extbase auf 13.4.40. Die Prüfung der URL-Zuordnung im geschützten Betrieb unterstützt jq 1.7.1 und 1.8.1. Der erneute Abruf des öffentlichen Bundestagsverzeichnisses am 20. November bestätigte dieselben 38 Mitglieder und 28 freigegebenen Porträts.

## Prüfungen

- Zentrale Version, Release-Unterlagen, Repository- und Browser-Verträge werden auf dem exakten Release-Commit geprüft.
- Der GitHub Release wird erst nach verifiziertem signiertem Tag, geprüftem Pages-Deployment und erfolgreicher Kontrolle aller drei Pflichtartefakte veröffentlicht.

## Bekannte Einschränkungen

- Version 0.28.0 ist ein Release Candidate vor dem gesondert freizugebenden gematik-Zielbetrieb.
- Die öffentliche Pages-Demo nutzt synthetische Kontaktdaten und ein öffentliches Bundestagsverzeichnis. Sie erlaubt den anonymen Zugriff. Für das private GKE-System und die Anmeldung über OIDC gelten eigene Prüfungen.
